Словарь терминов по нейросетям

  • Нейронная сеть — вычислительная система, имитирующая структуру биологических нейронных сетей.
  • Обучение с учителем — обучение на размеченных данных (вход-выход).
  • Сверточная нейросеть (CNN) — архитектура для обработки изображений и пространственных данных.
  • Рекуррентная нейросеть (RNN) — для работы с последовательностями (текст, временные ряды).
  • Градиентный спуск — метод оптимизации для минимизации ошибки нейросети.
  • Fine-tuning — дообучение предварительно обученной модели на новых данных.
  • GAN (Generative Adversarial Network) — генеративно-состязательная сеть для создания новых данных.
  • Реверс-инжиниринг ML — подход, при котором модели изучаются от готового кода к математике.
  • Transformer — архитектура на основе механизма внимания, основа современных LLM.
  • PyTorch / TensorFlow — основные фреймворки для глубокого обучения.
